# Publication Boundary

This repository is a public portfolio proof, not the production engineering system.

## Public

- high-level architecture;
- synthetic engineering project;
- generic requirement / risk / cost / quote concepts;
- deterministic demo logic;
- decision-readiness behavior;
- human-gate pattern;
- tests for the public demo.

## Private

- real customer and supplier information;
- project folders, drawings, CAD, photographs or quotations;
- customer-specific requirements and commercial terms;
- private infrastructure and credentials;
- production persistence/auth configuration;
- operational traces and internal automation;
- proprietary decision thresholds and company policy;
- paid/copyrighted technical reference material;
- books, standards, manuals and engineering source documents;
- historical project evidence that has not been explicitly cleared for publication.

## Method boundary

The showcase may refer to general systematic-engineering concepts, but it does not reproduce proprietary textbook content or claim conformance to a technical standard merely because a method name appears in the private project.

## Rule

Public GitHub proves the ability to structure and implement an engineering decision system without publishing customer data, valuable core logic or protected reference material.
